# Übungsanwendung Pizzabäcker

Eine einfache Webanwendung, welche eine Liste von Pizzas zurückgibt.

Die Liste der zurückgegebenen Pizzas kann in der Datei [src/main/java/de/ordix/pizzabaecker/PizzaController.java](./src/main/java/de/ordix/pizzabaecker/PizzaController.java) angepasst werden:

```java
public String[] pizzas = {
        "Magharita",
        "Salamie",
        "Speciale",
        "Thunfisch",
        "Schinken"
    };
```
