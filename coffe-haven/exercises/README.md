# GitLab CI/CD Seminar Übungen

Dieser Ordner enthält alle Übungsaufgaben für das GitLab CI/CD Seminar.

Die Aufgaben sind nach Kapiteln geordnet und bauen aufeinander auf. Innerhalb jedes Subordners findest du (mindestens) eine Markdown-Datei mit der Beschreibung der jeweiligen Übung und eine Musterlösung im Unterordner `solution`.

```markdown
exercises/
├── 00_introduction/
│   ├── 00_introduction.md
│   └── solution/
│       └── .gitlab-ci.yml
├── 02_pipeline_basics/
│   ├── 02_pipeline_basics.md
│   └── solution/
│       └── .gitlab-ci.yml
└── ...
```

Ziel der Übungen ist es Schritt für Schritt eine GitLab CI/CD Pipeline für ein E-Commerce Frontend Projekt zu erstellen und iterativ zu verbessern.
