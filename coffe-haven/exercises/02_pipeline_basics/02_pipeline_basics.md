# Pipeline Basics

Ziel dieser Übung ist es, unsere erste GitLab CI/CD Pipeline zu erstellen und zu starten.

## Aufgabe

1. Forke das GitLab CI-CD Workshop Template Repository. Folge dafür folgenden Schritten, nach der Anmeldung bei GitLab:
   - Drücke in der Leiste links auf `Groups` und wähle die Gruppe `Templates` aus
   - Klicke auf das Repository `Coffee Haven`
   - Drücke auf den `Fork` Button oben rechts und wähle unter `Select a namespace` deinen persönlichen Nutzernamen aus (z.B. `user1`)
   - Drücke unten auf den `Fork project` Button
2. Benutze den Pipeline-Editor unter `Build → Pipeline Editor`. Dort kannst du mit dem `Configure Pipeline` Button eine neue Pipeline erstellen. Committe die von GitLab vorgegebene Pipeline.
3. Beobachte die Ergebnisse (es könnte etwas dauern bis die Pipeline startet und durchläuft)

## Hinweise

- In der Leiste links findest du unter `Build → Pipelines` eine Übersicht aller Pipelines
- Wenn du auf die Badge in der Spalte `Status` klickst, gelangst du in die Pipeline-Übersicht, in der du alle Jobs wiederfindest
